## Перед установленням: доступ Google

Власник підтвердив: OAuth-проєкт **`likedex-extension-prod` перебуває в Testing**. Перед Connect приватно узгодьте з Vitalii Levinton доступ свого Google-облікового запису через ваш наявний канал спілкування з ним. Не публікуйте адресу Google в issue, PR або відгуку. Поки власник не додасть вас до test users, вхід може бути недоступним. Це окремий механізм від Chrome Web Store trusted testers; проєкт генерації голосу до нього не належить.

Не очікуйте безстрокової авторизації: [Google обмежує строк авторизації test users](https://support.google.com/cloud/answer/15549945?hl=en), і може знадобитися повторний Connect. Публічну OAuth verification ще не підтверджено. Ніколи не передавайте розробнику пароль Google, код підтвердження, токен чи файл із даними авторизації.

## Установлення

1. Відкрийте [офіційний GitHub prerelease](https://github.com/vitali1024/likedex/releases/tag/capstone-preview-2026-10-08-2) і завантажте [ZIP попередньої версії](https://github.com/vitali1024/likedex/releases/download/capstone-preview-2026-10-08-2/likedex-tester-preview-0.1.0-347cb3e-chrome.zip). Установлюйте лише пакет цього репозиторію, якому ви довіряєте.
2. Розпакуйте ZIP у постійну локальну папку, яку не видалятимете під час тестування. У вибраній папці має лежати `manifest.json` разом із `background.js`, `options.html`, `sidepanel.html`, `popup.html` та підпапками ресурсів.
3. Відкрийте Google Chrome для комп'ютера, версія 141 або новіша.
4. Перейдіть на `chrome://extensions`.
5. Увімкніть **Developer mode / Режим розробника**.
6. Натисніть **Load unpacked / Завантажити розпаковане розширення**.
7. Виберіть **розпаковану папку з кореневим `manifest.json`**. Не вибирайте ZIP або папку на рівень вище.
8. Переконайтеся, що в списку є Likedex 0.1.0 з ID `mmefiakgfhddiojfdnkfpfpbkgbfgkgj`. Інший ID — привід зупинитися й приватно повідомити власника до Connect.
9. Відкрийте меню Chrome **Extensions / Розширення** та закріпіть значок Likedex.
10. Натисніть значок Likedex на панелі інструментів.
11. Виберіть **Open Full Library** або **Open Side Panel**.
12. Прочитайте пояснення доступу й приватності, погодьтеся за бажанням та виконайте **Connect YouTube** через справжнє вікно Google. Доступ до YouTube лише для читання.
13. Натисніть **Sync**, щоб створити локальне дзеркало. Дочекайтеся правдивого статусу завершення; підключення саме по собі не означає, що синхронізація вже відбулася.
14. Спробуйте пошук, фільтри, сортування та деталі. У широкому Full Library результати й деталі видно одночасно, а Reset view залишається на панелі інструментів. У вузькому режимі й Side Panel повернення виконує Back to library.

Розпакована версія **не оновлюється автоматично через Chrome Web Store**. Новий пакет і порядок оновлення повідомляє власник; не змішуйте папки різних версій. За потреби перевірте ZIP за [SHA256SUMS.txt](https://github.com/vitali1024/likedex/releases/download/capstone-preview-2026-10-08-2/SHA256SUMS.txt): SHA-256 `3C664881E8A4A54512E204E8E9396E92C49281DC8B190623DB330C73400B2B07`.

## Межі цієї версії

- Підтримуються лише YouTube Liked Videos. Likedex не редагує вподобання або плейлисти.
- **Export Data, Clear Local Data і повний Disconnect/Revoke UI ще не доступні.** Наявні службові механізми очищення не замінюють цих майбутніх кнопок.
- Приватні, видалені або записи з невідомою доступністю можуть зберігатися для коректності синхронізації, але не входять до основного списку доступних відео. Доступність відображає останні перевірені метадані, а не гарантує відтворення на YouTube.
- Звичайний пошук, фільтри й деталі працюють із локальним дзеркалом. Connect, Sync, необхідні перевірки авторизації та зображення можуть звертатися до Google/YouTube. Автоматичного Sync немає.
- Дані підлягають обмеженню свіжості до 30 календарних днів; прострочені дані або неможливість обов'язково перевірити авторизацію блокують доступ і запускають очищення. Звичайна помилка Sync зберігає попередній успіх, поки дані авторизовані й не прострочені. Після очищення може знадобитися Connect і новий Sync.
- Store item має останній підтверджений стан **Draft**. Store review/publication, публічна OAuth verification, незалежна перевірка ризиків і фінальний приймальний тест точного пакета з реальним обліковим записом ще не завершені.

## Приватність, помилки й видалення

Локально в IndexedDB зберігаються ідентифікатор власника YouTube, належність відео до Likes, необхідні метадані й обмежені відомості про стан/свіжість синхронізації. Паролі й refresh tokens Likedex не збирає; доступом керує Chrome. Повний [інвентар і контракт даних](privacy-and-data.md) відокремлює реалізовані механізми від запланованих контролів.

Повідомляйте лише очищений від приватних даних текст помилки та кроки відтворення. Приховайте назву/ID особистого каналу, адресу Google, приватні назви відео, сповіщення й усі токени на знімках. Не надсилайте дамп бібліотеки або профіль браузера. Використайте [шаблон відгуку](tester-feedback.md).

Щоб видалити розширення, відкрийте `chrome://extensions`, знайдіть Likedex і натисніть **Remove / Видалити**. [Інструкція Chrome](https://support.google.com/chrome/answer/2664769?hl=en). Це не обіцянка видалення ваших окремих файлів/резервних копій і **не відкликає автоматично Google-авторизацію**. Окремо відкрийте [підключення Google Account](https://myaccount.google.com/connections), знайдіть Likedex і приберіть його доступ за інструкціями Google. Для припинення тестування зробіть обидва кроки; не покладайтеся на ще не реалізований Disconnect UI.
